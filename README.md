# Operating System Lab Assignment 6

This assignment focuses on understanding and implementing different techniques for handling deadlocks and synchronization in xv6.

## What I implemented

- **Q1:** Banker's Algorithm for deadlock avoidance.
- **Q2:** Deadlock detection using a Resource Allocation / Wait-for Graph.
- **Q3:** Deadlock prevention using resource ordering with two locks.
- **Q4:** Multi-resource synchronization with deadlock prevention.

The programs were implemented and tested in the xv6 environment, with output logs included to demonstrate the working of the different approaches.
